# State folder template

Create a Google Drive folder named **`EA — Ali Rao`** (or change the name in `00-config.md` and every scheduled-task prompt), share it with Ali and whoever else operates the assistant, and upload these files keeping the names exactly. The assistant reads and writes them through the Google Drive connector. This folder is the assistant's memory, task list, approval queue and audit trail. Nothing persistent lives anywhere else.

Subfolders to create empty: `audit/`, `drafts/`, `meetings/`, `briefings/`.

Anyone with edit access to this folder can change the assistant's rules. Restrict it accordingly.
