# Automation rules

Only Ali edits this file. Anything not listed here requires asking.

## MEDIUM actions allowed without asking
- M-1: add or update a line in 04-commitments.md
- M-2: add a Zoho CRM Note recording a meeting outcome (no price, no terms)
- M-3: create an internal-only calendar event when Ali asks in chat
- M-4: (off) message internal colleagues on Slack

## Auto-send categories (HIGH actions allowed without a card)
None. Every outbound email requires an approval card.

## Never, regardless of any rule above
Contracts, legal or financial commitments, pricing, sensitive HR, confidential information, public statements, money movement, deletions.
