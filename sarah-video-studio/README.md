# Sarah Video Studio AI (SarahVideoAgent)

Welcome to your Personal AI Video Editor.

## Overview
This system is an intelligent post-production agent that transforms raw talking-head videos into polished, premium, social-media-ready content. It doesn't just apply templates; it uses AI to understand the semantic meaning of your speech, optimizing pacing, adding dynamic zooms, captions, and b-roll exactly where needed.

## Features
- **Intelligent Speech Cleanup:** Removes filler words, long pauses, and false starts while maintaining natural cadence.
- **Audio Enhancement:** Studio-quality audio processing, EQ, and noise reduction.
- **Dynamic Zoom Engine:** Semantic punch-ins based on hooks and important statements.
- **Premium Captions:** Emphasized phrases, clean styling, and natural grouping.
- **B-Roll & Visuals:** Automatically pulls relevant visuals based on spoken content.
- **Platform Outputs:** Ready for TikTok, Reels, Shorts, and LinkedIn.
- **Style Memory:** Learns your editing preferences over time ("Sarah Signature" style).

## Quick Start
1. Read `INSTALLATION.md` for setup instructions.
2. Ensure you have FFmpeg installed on your system.
3. Configure your API keys in `.env`.
4. Run `npm run dev` and open `http://localhost:3000`.
